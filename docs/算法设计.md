# 算法设计

## 题意

n ≤ 100000，1 ≤ m ≤ 1000，1 ≤ a[i] ≤ 100000。统计至少存在一对相邻元素绝对差 ≤ m 的子序列，模数 P = 1000000007。单元素不 beautiful；不同下标选择分别计数。

## 采用 beautiful 状态直接计数

下标从 1 开始。dp[i] 表示以位置 i 结尾的 beautiful 子序列数。处理 i 之前维护 B = sum(dp[j], j < i)。

对于倒数第二个位置 j：

- 若 |a[j]-a[i]| > m，此前子序列必须已 beautiful，贡献 dp[j]。
- 若 |a[j]-a[i]| ≤ m，此前任何以 j 结尾的子序列都可以，贡献 2^(j-1)。因为 j 必选，前 j-1 个位置任意选。

令 Anear 为附近位置的 2^(j-1) 之和，Dnear 为附近位置的 dp[j] 之和，则：

```text
dp[i] = B - Dnear + Anear
```

单元素 [a[j]] 已包括在 2^(j-1) 中，能够贡献长度为 2 的 beautiful 子序列。dp[i] 本身不加入单元素，最终无需减 n。

## 按值分桶

all[v] 累加此前 a[j]=v 的 2^(j-1)，beautiful[v] 累加此前 a[j]=v 的 dp[j]。每个桶存总和，而非逐个元素列表。

```text
B = 0, power = 1，桶清零
对每个当前值 x：
    L = max(1, x-m), R = min(100000, x+m)
    Anear = all[L..R] 的和（取模）
    Dnear = beautiful[L..R] 的和（取模）
    dpi = (B - Dnear + Anear + P) % P
    all[x] = (all[x] + power) % P
    beautiful[x] = (beautiful[x] + dpi) % P
    B = (B + dpi) % P
    power = power * 2 % P
输出 B
```

必须先查询后插入，保证只考虑 j < i。使用足够宽的整数处理中间运算，勿使用浮点 pow 计算模幂。

## 正确性要点

每个长度至少为 2、以 i 结尾的子序列都有唯一的倒数第二个位置 j。按最后一对是否满足阈值分成两个互斥且完备的类别，分别使用上述两条转移。不同 j 对应不同下标选择，不重复计数。最后按唯一结尾位置求和得到所有 beautiful 子序列。

## 复杂度

直接扫描附近桶：时间 O(nm + V)，空间 O(V)，V=100000。最坏约有 2 亿次桶访问，是否超时需实际测量。

可用两棵树状数组维护桶的区间和，将时间降至 O(n log V + V)，空间 O(V)。可进一步合并维护 all-beautiful，但报告应以最终实际实现为准。
