# 测试说明

## 三个文件各做什么

- `scripts/gen.py`：生成输入，调用 ref 计算答案，写入 `data/generated/*.in` 与同名 `.out`。
- `scripts/ref.py`：枚举所有下标子集，按题意检查选出子序列的相邻元素，不使用 main.c 的 DP。只用于 n ≤ 20。
- `scripts/run_tests.py`：生成本轮数据、编译当前 main.c、运行程序、比较答案，打印 case / N / M / result / time 表格，最后给出汇总。

## 使用方法

在仓库根目录运行：

```sh
# 只生成数据，不编译、不运行 main.c
python scripts/gen.py
# 生成数据并自动评测，默认 20 组随机数据
python scripts/run_tests.py
# 不生成随机测试，只评测固定测试
python scripts/run_tests.py --random 0
# 固定随机种子，生成 200 组随机数据并评测
python scripts/run_tests.py --random 200 --seed 42
```

随机数据范围 n=2..12、m=1..5、值=1..15。固定测试由本项目设计，不是官方样例。原有 data/*.in 及 .out 保留并纳入评测；如果与生成的测试同名，以原有文件为准，避免重复运行。添加手工测试时需同时提供同名 .out。

生成器只覆盖 data/generated/ 中本轮使用的同名文件；旧文件不会删除，但不在本轮清单中的旧生成文件不会被评测。默认单例超时 3 秒，可用 --timeout 修改；可用 --cc 指定编译器、--source 指定源码。

空输出、多余文字、错误答案、异常退出、超时均判失败。允许输出首尾空白。返回码 0 表示全通过，1 表示失败或评测未完成。

## 本轮验证

2026-11-15：绕过评测脚本直接编译运行原 main.c，对输入 `2 3` 和 `2 5` 得到 9，期望为 1。另用独立 C 穷举程序验证评测器，10 组固定及 200 组随机用例全部通过。该 C 程序仅用于评测器开发验证，未替换 main.c。

本测试针对小规模正确性，不证明 n=100000 时的性能。性能测试应记录编译器、优化参数、运行环境与耗时；全相同数组可用 (2^n-1-n) mod 1000000007 校验。
