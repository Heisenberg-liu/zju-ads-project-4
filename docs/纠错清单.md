# 纠错清单与复核结论

详细的问题、原因与修复记录见《实验报告》4.3 节。当前 `main.c` 已修复以下问题：

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 初始小数据全部错误 | 输入阶段提前把当前和未来位置贡献放入桶 | 改为从左到右查询后更新 |
| 桶中 DP 更新位置错误 | 用位置 i 代替数值 a[i] 作为桶编号 | 改为按当前元素值 record 更新 |
| 大数计数不准确 | 用浮点 pow，且计数未及时取模 | 用整数倍增维护 power，计数更新取模 |
| 小数据通过、较大重复数据失败 | bucket_allcase 的累加漏取模 | 补上该桶更新的取模 |
| 内存越界 | DP 改为 long long 后仍按 sizeof(int) 分配 | 按 sizeof(long long) 分配，最终移除动态数组 |
| 输出类型不一致 | long long 表达式使用 %d 输出 | 当前使用 %lld |
| 空间占用 | record 数组与 DP 数组没有必要 | 改为单变量，空间降至 O(V) |
