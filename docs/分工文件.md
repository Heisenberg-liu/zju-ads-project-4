# 小组分工

本project由第一组刘钰栋和郭其安合力完成


| 成员 | 主要职责 | 交付物 |
| --- | --- | --- |
| 刘钰栋 | 编写算法代码；修复问题；构建与执行正确性、边界及性能测试 | 程序源码、测试数据/脚本、真实运行记录与性能数据 |
| 郭其安 | 撰写报告；核对题意、状态定义、证明和复杂度；检查代码并提出纠错意见；复核修复 | 项目报告、纠错清单、复核结论 |

## 协作流程

1. 两人确认题意与 DP 定义，使用 `算法设计.md` 作为共同依据。
2. 刘钰栋完成实现并运行测试，记录运行命令、环境、结果与失败用例。
3. 郭其安审查代码和测试结果，在 `纠错清单.md` 中登记发现的问题。
4. 刘钰栋修复并重新测试，同郭其安复核后将对应问题标记为已完成。
5. 郭其安根据最终代码与真实实验数据完成报告；刘钰栋检查报告中的实现和测试描述。
6. 提交前共同确认源码可编译、测试可复现、报告与实现一致，且不含未填写的占位内容。

## 责任边界

“纠错”包含发现、分析与复核问题；具体代码修改由刘钰栋负责，报告修改由郭其安负责。两人可以讨论和协助，但应保留真实贡献记录，不将计划写成已完成工作。
